## این پروژه چیست؟

یک برنامهٔ کنسولی پایتون با نام «Kapp» که مجموعه‌ای از ابزارهای کوچک را در قالب یک منوی
متنی گرد هم جمع کرده است. ایدهٔ آن زمان این بود که یک برنامهٔ همه‌کارهٔ ساده داشته باشم. و هرچیز و اسکریپتی به ذهنم میرسید و یا میدیدم، بهش اضافه میکردم.

قابلیت‌های موجود در برنامه:

- ماشین‌حساب (با استفاده از `eval`)
- تشخیص عدد اول و مرکب
- تولید دنبالهٔ فیبوناچی
- جدول ضرب
- محاسبهٔ جذر
- محاسبهٔ اضلاع مثلث با قضیهٔ فیثاغورس (به‌همراه نمایش مراحل)
- محاسبهٔ فاصلهٔ بین دو نقطه و فاصلهٔ نقطه از خط
- کار با تقویم (تبدیل روز به سال/ماه/روز و نمایش تقویم ماه)
- نمایش مجموعه‌ای از نمادهای ریاضی
- خواندن متن با صدا (Text-to-Speech با `pyttsx3`)
- دو بازی کوچک تصادفی
- ساخت جدول با `PrettyTable` (از یک تا پنج ستون)
- استخراج پسورد شبکه‌های وای‌فای ذخیره‌شده در ویندوز

رمز ورود به برنامه: `123`

---

## نحوهٔ اجرا

```bash
pip install prettytable pyttsx3
python Kapp.py
```

سپس رمز `123` را وارد کنید و از منو استفاده کنید.

نکته: بخش مربوط به وای‌فای فقط روی ویندوز کار می‌کند، چون از دستور `netsh wlan` استفاده می‌کند.

## نکاتی دربارهٔ کد

این بخش را برای شفافیت می‌نویسم. این کد برای زمان خودش و در سطح کسی که تازه با برنامه نویسی آشنا شده
نوشته شده و طبیعتاً کاستی‌های زیادی داره:

- تمام کد در یک فایل قرار دارد و هیچ ماژول‌بندی یا جداسازی منطق از رابط کاربری وجود ندارد.
- برای ماشین‌حساب از `eval` استفاده شده که از نظر امنیتی روش مناسبی نیست.
- رمز ورود به‌صورت مستقیم در کد نوشته شده است.
- برای بازگشت به منوها از فراخوانی بازگشتی تابع به‌جای حلقه استفاده شده که در استفادهٔ
  طولانی می‌تواند به خطای بازگشت بیش از حد منجر شود.
- بخش‌های زیادی از کد (مثل منوی بازگشت و پیام‌ها) تکرار شده‌اند.
- تعدادی غلط املایی و تایپی در متن‌ها و نام متغیرها وجود دارد.
- نام‌گذاری متغیرها و توابع در بسیاری از موارد معنادار نیست.
- مدیریت خطا تقریباً وجود ندارد و ورودی نامعتبر می‌تواند باعث توقف برنامه شود.
- بخش مربوط به وای‌فای از یک نمونهٔ آموزشی اقتباس شده و در آن زمان درک کاملی از آن نداشتم.
- هیچ تست خودکاری برای پروژه نوشته نشده است.

این‌ها را نه به‌عنوان نقد، بلکه به‌عنوان تصویر واقعی از یک پروژهٔ یادگیری ذکر می‌کنم.
